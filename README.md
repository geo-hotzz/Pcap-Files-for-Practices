Overview
This repository contains curated packet capture (PCAP) files used for practicing network analysis, traffic reconstruction, and basic forensic investigation techniques.
The datasets are intentionally structured to simulate common scenarios encountered during security assessments and CTF-style challenges.

Objective
-----------------------
Analyze network traffic using Wireshark and tshark
Reconstruct TCP streams
Extract transferred files from HTTP traffic
Identify file signatures and perform manual carving
Validate file integrity using hashing techniques

Tools Used
----------------------------
Wireshark
tshark
tcpdump
binwalk
xxd
dd
sha256sum

Skills Practiced
-----------------------------
Protocol inspection (HTTP, TCP)
Packet stream reconstruction
Traffic filtering and analysis
Binary inspection
Evidence extraction

Notes
----------------------------
These PCAP files are for educational and lab practice only.
No real-world sensitive traffic is included.
File hashes are provided when applicable for integrity verification.
